## Giới thiệu
**Booking Hotel** là dự án xây dựng hệ thống đặt phòng khách sạn trực tuyến, cho phép người dùng tìm kiếm khách sạn, xem thông tin chi tiết phòng, đặt phòng và quản lý lịch sử đặt phòng một cách thuận tiện.

Dự án được thực hiện nhằm áp dụng kiến thức về phân tích hệ thống, thiết kế cơ sở dữ liệu và phát triển phần mềm theo mô hình hiện đại, dễ mở rộng và bảo trì.

##  Mục tiêu dự án
- Xây dựng hệ thống đặt phòng khách sạn thân thiện với người dùng  
- Quản lý thông tin khách sạn, loại phòng và đơn đặt phòng  
- Nâng cao kỹ năng làm việc nhóm và phát triển ứng dụng thực tế

## 🚀 Hướng dẫn cài đặt

### 1. Clone Repository
```bash
git clone https://github.com/yourusername/HotelBooking.git
cd HotelBooking
```

### 2. Cấu hình Google Maps API

1. Truy cập [Google Cloud Console](https://console.cloud.google.com/)
2. Tạo dự án hoặc chọn dự án hiện có
3. Bật APIs: Google Maps Android API, Places API
4. Tạo API Key
5. Tại thư mục gốc dự án, tạo file `local.properties`:
```properties
GOOGLE_MAPS_API_KEY=your_api_key_here
```

### 3. Cấu hình Firebase

1. Truy cập [Firebase Console](https://console.firebase.google.com/)
2. Tạo dự án mới
3. Tạo ứng dụng Android
4. Tải file `google-services.json`
5. Đặt file vào `SRC/app/`

### 4. Mở dự án trong Android Studio

1. Mở Android Studio
2. Chọn **File** → **Open**
3. Chọn thư mục `SRC`
4. Chờ Gradle đồng bộ hóa

### 5. Chạy ứng dụng

```bash
# Sử dụng emulator hoặc thiết bị Android thực tế
./gradlew installDebug
```

### 6. Build APK

```bash
# Debug APK
./gradlew assembleDebug

# Release APK
./gradlew assembleRelease
```

## 🏗️ Kiến trúc ứng dụng

Ứng dụng được xây dựng theo **Clean Architecture** pattern:

```
┌─────────────────────────────────────┐
│     PRESENTATION LAYER              │
│  (UI, ViewModels, Navigation)       │
└────────────┬────────────────────────┘
             │
┌────────────▼────────────────────────┐
│     DOMAIN LAYER                    │
│  (Use Cases, Repositories, Models)  │
└────────────┬────────────────────────┘
             │
┌────────────▼────────────────────────┐
│     DATA LAYER                      │
│  (Datasources, Mapping, Network)    │
└─────────────────────────────────────┘
```

### 3 Lớp chính:

1. **Presentation Layer** - UI, ViewModels, Navigation
2. **Domain Layer** - Business logic, Use cases
3. **Data Layer** - Database, API, Repositories

Mỗi feature theo cấu trúc:
```
features/newfeature/
├── data/           # Data layer
├── domain/         # Domain layer
├── presentation/   # Presentation layer
└── di/            # Dependency Injection
```

```
├── id: string

├── id: string

└── imageUrls: array

bookings/
├── id: string
├── userId: string
├── hotelId: string
├── roomId: string
├── checkInDate: timestamp
├── checkOutDate: timestamp
├── totalPrice: number
├── status: string
└── createdAt: timestamp
```

### Security Rules

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /hotels/{document=**} {
      allow read: if true;
      allow write: if request.auth != null && 
                      request.auth.token.admin == true;
    }
    match /bookings/{document=**} {
      allow read: if request.auth != null;
      allow write: if request.auth != null;
    }
  }
}
```
